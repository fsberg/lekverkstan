# Lekverkstan

Lokal app för att bygga MTG-lekar (Commander och Modern), bocka i vilka kort du har och planera köp.

Starta med `start.cmd` och öppna sedan http://localhost:8793/. Servern lyssnar bara på den här datorn.

- **Kortdata:** Scryfall
- **Lager och pris:** Alara Games, cachas i 6 h
- **Köp via Cardmarket:** önskelista att klistra in, därefter Shopping Wizard med Sverige som säljarland
- **Svenska Magic:** länk, och kortnamnet kopieras

Data sparas i `data/`: lekar, samling och cachar.
